# Math and String Utils Example

This project provides simple utilities for basic math operations and string manipulation via a sample script.

## Overview

The script demonstrates how to use reusable functions from utility modules for:

- Addition of numbers
- Multiplication of numbers
- Reversing a string

## Project Structure

├── main.py # Example script using utility functions
└── utils/
├── math_utils.py # add() and multiply() implementations
└── string_utils.py # reverse_string() implementation

## Usage

Run the main script from your terminal:


### Example Output

Addition: 15
Multiplication: 12
Reversed: kihtraK


## Available Functions

**In `utils/math_utils.py`:**
- `add(a, b)`: Returns the sum of `a` and `b`.
- `multiply(a, b)`: Returns the product of `a` and `b`.

**In `utils/string_utils.py`:**
- `reverse_string(s)`: Returns the reversed version of the string `s`.

## Requirements

- Python 3.x

> Ensure that the `utils` directory is in the same folder as `main.py`, and contains an `__init__.py` file if you plan to use it as a package.
